# Periodic Table Database

A Bash and PostgreSQL project from the freeCodeCamp Relational Database curriculum.

### Usage

Run the element lookup script with an atomic number, symbol, or name:

    ./element.sh 1
    ./element.sh H
    ./element.sh Hydrogen

The program displays the element's atomic number, symbol, name, type,
atomic mass, melting point, and boiling point.

### Files

- element.sh: Bash program for querying elements.
- periodic_table.sql: PostgreSQL database dump.
